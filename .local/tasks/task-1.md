# Wireframe Layout Options for Case Study Pages

  ## Objective
  Delete all 9 old canvas design mockups and replace them with hand-drawn paper wireframe representations showing 3 structural layouts for a UX case study page.

  ## Delete from canvas
  Shapes: liffo-v1, liffo-v2, liffo-v3, fff-v1, fff-v2, fff-v3, twoHL-v1, twoHL-v2, twoHL-v3, col-label-1, col-label-2, col-label-3, row-label-liffo, row-label-fff, row-label-2hl

  ## 3 Wireframe Layouts
  All use paper sketch style: cream #fdf8f0 BG + grid pattern + SVG feTurbulence filter + X-boxes for images + text line placeholders + hatch fills for buttons.

  ### Layout A — Single Column Editorial
  Full-width sections stacked top-to-bottom. Left dot-rail progress indicator. Nav bar → hero (title, role, timeline, metric pills) → 10 sections each with mono label + heading line + body text placeholders + content blocks.

  ### Layout B — Side Nav + Content
  Left ~220px fixed nav rail (back arrow, logo, section anchor list with dots). Right scrollable column: 10 section panels with left accent borders. 2-col header.

  ### Layout C — Card Grid / Bento
  Full-width hero. Row of 4 metric cards. 2-col brief+research. Bold reframe card. 3-col exploration options. 2-col decisions+screens. 4-col metric outcomes. Full-width reflection.
